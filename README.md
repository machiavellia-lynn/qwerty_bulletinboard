# Group Bulletin Board

A lightweight web application built for Raspberry Pi Zero 2W.

## Description

Group Bulletin Board is a simple web application that allows group members to post, view, and delete short announcements or messages. It is designed to run on resource-constrained hardware (RPi0 2W) while demonstrating a classic 3-tier web architecture.

## Architecture

- **Presentation Layer** — HTML/CSS frontend rendered by the browser
- **Application Layer** — PHP scripts handling business logic and HTTP requests
- **Data Layer** — MySQL (or SQLite) relational database storing messages

## Features

- Post a message with your name and content
- View all posted messages in chronological order
- Delete a message

## Tech Stack

- PHP
- MySQL / SQLite
- Apache / Lighttpd (lightweight for RPi0)
- HTML/CSS
